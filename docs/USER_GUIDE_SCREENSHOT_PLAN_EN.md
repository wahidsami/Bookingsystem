# User Guide Screenshot Plan

This is not a normal user guide.  
It is a **shot list** for capturing documentation screenshots.

The purpose is to tell Antigravity or any browser-based capture tool:

- which page to open
- whether the screenshot should be **full page** or a **specific element**
- what must be visible in the shot
- which interactions should happen before capture

---

## General Rules

### When to take a full-page screenshot

Use a **Full Page Screenshot** when:

- the page is long
- we want to document every section
- the page is a list, dashboard, or report

### When to take an element screenshot

Use an **Element Screenshot** when:

- the item is small or important on its own
- we need to document one card, drawer, or menu
- we want to highlight hover states, badges, or popovers

### When to take two screenshots for the same page

Take two shots when the page has:

- the main page in a closed state
- a drawer or modal opened on top

or when it has:

- a list / board
- the detail view inside the list / board
