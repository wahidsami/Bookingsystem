# دليل لقطات الشاشة لشرح المستخدم

هذا الملف ليس دليل استخدام عادي.  
هو **قائمة تنفيذ لالتقاط لقطات الشاشة** أثناء توثيق الشاشات في النظام.

الهدف منه أن يتمكن Antigravity أو أي أداة تصوير من معرفة:

- ما هي الصفحة المطلوبة
- هل نحتاج **لقطة شاشة كاملة** أم **لقطة عنصر محدد**
- ما الذي يجب أن يظهر داخل اللقطة
- ما الذي يجب فتحه قبل التصوير

---

## قواعد عامة

### متى نستخدم لقطة شاشة كاملة؟

استخدم **Full Page Screenshot** عندما:

- تكون الصفحة طويلة
- نريد توثيق كل الأقسام
- الصفحة عبارة عن قائمة أو لوحة أو تقرير

### متى نستخدم لقطة عنصر محدد؟

استخدم **Element Screenshot** عندما:

- يكون العنصر صغيرًا أو مهمًا لوحده
- نريد توثيق بطاقة واحدة أو Drawer أو Menu
- نريد إبراز حالة hover أو badge أو popover

### متى نستخدم لقطتين لنفس الصفحة؟

خذ لقطتين عندما تحتوي الصفحة على:

- **الصفحة الرئيسية مغلقة**
- **Drawer أو Modal مفتوح**

أو عندما تحتوي على:

- **القائمة الرئيسية**
- **تفاصيل عنصر داخلها**
