# Refah Mobile SVG Icon Pack

Place all replacement SVG icons in this folder using the exact filenames listed in:

- `docs/MOBILE_ICON_REPLACEMENT_MAP.md`

Notes:
- Use `viewBox="0 0 24 24"` for most UI icons unless stated otherwise.
- Keep SVGs monochrome where possible; app code will tint many icons.
- For brand/social icons (Google, Instagram, etc.), preserve official colors if desired.
- For logos (brand marks), prefer transparent background.
