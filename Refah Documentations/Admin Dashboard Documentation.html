مقدمة وتفاصيل تقنية

مقدمة

تُعتبر لوحة التحكم الإدارية في نظام رفاه المركز الرئيسي لإدارة وتشغيل المنصة متعددة العملاء (Multi-Tenant Platform)، حيث توفر للإدارة العليا وفِرق التشغيل جميع الأدوات اللازمة لإدارة العملاء، مراقبة العمليات، التحكم في الخطط التجارية، متابعة الأداء المالي، وإدارة إعدادات النظام المركزية.

تمثل اللوحة العقل التشغيلي والتجاري لمنصة رفاه، حيث تجمع بين:

  • الإدارة التشغيلية
  • الحوكمة والرقابة
  • إدارة الاشتراكات
  • التحكم المالي
  • إدارة الخطط التجارية
  • مراقبة نمو المنصة

وتوفر بيئة متكاملة لإدارة دورة حياة العملاء والمنشآت داخل المنصة.

الفئات المستهدفة والوظائف

2. الهدف من النظام

تم تطوير لوحة التحكم الإدارية لتكون مركز التحكم الكامل لمنصة رفاه، حيث تساعد الإدارة على:

  • إدارة العملاء والمنشآت
  • إدارة المستخدمين
  • مراقبة الأداء المالي
  • إدارة الخطط والاشتراكات
  • متابعة العمولات والإيرادات
  • إدارة إعدادات النظام العامة
  • مراقبة الأنشطة التشغيلية
  • إدارة التوسع التجاري للمنصة

3. الفئات المستهدفة

تم تصميم لوحة التحكم لتخدم الفئات التالية:

مدير النظام الإدارة العليا فريق التشغيل فريق الدعم الفني الإدارة المالية فريق إدارة الاشتراكات إدارة الحوكمة والتدقيق

4. الوظائف الرئيسية للنظام

توفر لوحة التحكم مجموعة واسعة من الوظائف الإدارية والتجارية، وتشمل:

  • إدارة العملاء والمنشآت: اعتماد وتفعيل الحسابات، إدارة المستخدمين والعملاء النهائيين.
  • إدارة الخطط التجارية: إدارة الخطط والاشتراكات ومتابعة الإيرادات والعمولات.
  • المراقبة والتحكم: مراقبة الأداء التشغيلي، مراجعة الأنشطة والسجلات.
  • الإدارة العامة: إدارة إعدادات النظام، مراقبة التنبيهات والإشعارات، إدارة المزايا التجارية والتسويقية.

إدارة العملاء والمالية

6.2 إدارة العملاء والمنشآت (Clients / Tenants Management)

يُستخدم هذا القسم لإدارة جميع المنشآت والعملاء داخل منصة رفاه.

الوظائف المتاحة حالات العملاء
  • عرض قائمة العملاء
  • البحث والتصفية
  • مراجعة بيانات المنشآت
  • مراجعة المستندات والتحقق
  • اعتماد أو رفض الحسابات
  • تعليق أو إعادة التفعيل
  • مراجعة السجل التشغيلي
  • معتمد
  • قيد المراجعة
  • موقوف
  • مرفوض

6.3 إدارة المستخدمين (Users Management)

يوفر هذا القسم أدوات لإدارة مستخدمي المنصة النهائيين.

  • البحث عن المستخدمين ومراجعة الحسابات
  • مراجعة الحجوزات والمعاملات
  • تعديل الأرصدة أو نقاط الولاء
  • تفعيل أو تعطيل الحسابات
  • مراجعة حالة التحقق

مميزات تشغيلية: تحسين الرقابة على الحسابات، متابعة النشاطات المشبوهة، دعم فرق خدمة العملاء.

6.4 الإدارة المالية (Financial Section)

يوفر أدوات متقدمة لمراقبة الأداء المالي للمنصة.

  • مراجعة الإيرادات ومتابعة نمو الأرباح
  • تحليل العمولات
  • مراجعة بيانات العملاء المالية
  • متابعة المدفوعات والتحويلات

ملاحظة تشغيلية: بعض وظائف التحويلات والمدفوعات ما زالت محدودة بحسب حالة التكامل الحالية.

6.5 سجل الأنشطة والتدقيق (Activity Log)

يُعتبر هذا القسم أحد أهم عناصر الحوكمة والرقابة داخل المنصة.

  • تسجيل جميع العمليات الإدارية
  • تصفية العمليات حسب التاريخ أو النوع
  • مراجعة تفاصيل الإجراءات
  • تتبع التغييرات داخل النظام

أهداف القسم: تعزيز الشفافية، دعم التدقيق الداخلي، تحسين الحوكمة، مراقبة العمليات الحساسة.

6.6 الإعدادات العامة (Settings)

يوفر هذا القسم إدارة الإعدادات العامة للمنصة.

  • إدارة نسب العمولات
  • إدارة إعدادات المنصة
  • إدارة حسابات المشرفين
  • الإعدادات العامة
  • مراجعة بطاقات الخطط والأسعار

6.7 إدارة الباقات والخطط التجارية

يُعتبر هذا القسم أحد أهم المكونات التجارية داخل منصة رفاه، حيث يسمح بإدارة نموذج الاشتراكات التجارية الخاص بالمنصة.

البطاقات التجارية المعروضة: السعر الشهري، سعر 6 أشهر، السعر السنوي، حالة التفعيل، حالة الباقة المميزة.

7. إدارة الباقات التجارية

يوفر النظام محركاً متكاملاً لإدارة الخطط التجارية والاشتراكات الخاصة بالعملاء.

  • إنشاء الباقات وتعديل الباقات
  • إدارة حدود الاستخدام وإدارة المزايا التجارية
  • إدارة الأسعار وحالة التفعيل وتحديد الباقات المميزة

المزايا والتسعير

7.3 المزايا الأساسية للمنصة

يمكن تفعيل أو تعطيل مزايا متعددة داخل كل باقة.

المزايا التشغيلية

  • إدارة المنتجات والطلبات
  • المراسلات الداخلية
  • التقارير
  • إدارة الرواتب
  • تخصيص الصفحة العامة

المزايا التسويقية

  • إشعارات WhatsApp
  • الإشعارات التسويقية داخل التطبيق
  • مساعد الذكاء الاصطناعي للمحتوى
  • الرسائل البريدية الترويجية
  • تحسين الظهور في البحث

مزايا الترويج داخل المنصة

  • الظهور ضمن “جديد في رفاه”
  • الظهور في البطاقات المميزة
  • إدارة العروض الخاصة Hot Deals
  • عدد المنتجات المميزة

7.4 نموذج التسعير التجاري (Pricing Model)

يعتمد احتساب أسعار الباقات على نموذج تسعير ديناميكي يتضمن:

  • رسوم الاشتراك الأساسية
  • تكلفة الموارد
  • تكلفة المزايا الإضافية
  • عمولة المنصة
  • ضريبة القيمة المضافة 15%
القيم المالية المخزنة: يقوم النظام بحساب وتخزين السعر الشهري، سعر 6 أشهر، والسعر السنوي.

أهداف محرك التسعير: تسهيل بناء الباقات، احتساب التكلفة بشكل تلقائي، مراجعة الأثر التجاري قبل النشر، دعم التوسع التجاري للمنصة.

10. ملاحظات تشغيلية مهمة
